# Identidad Edinun

Recursos exclusivos del tema `EDINUN`, asignado por UUID de organización desde Administración maestra → Identidad visual.

- `assets/logo.png`: recurso oficial https://www.edinun.com/images/LogoEdinun_bordeAzul.png, consultado el 20-10-2026. No se altera el logo.
- `theme.ts`: azul #006EB6 presente en los estilos oficiales; acento rojo #D32829 adaptado del logo. La barra #12385B es una variante oscura para asegurar legibilidad en la aplicación.
- Tipografía Arial/Helvetica, observada en el CSS oficial. Son fuentes del sistema; no se redistribuyen archivos de fuente.
- Referencias: https://www.edinun.com/ y su hoja `234_SitioEdinun_14_agosto_2026_PUBLICADO.css`.

Los colores semánticos de error, advertencia y éxito pertenecen al sistema, no a la marca. Para otra empresa, crear un paquete hermano o seleccionar un tema CUSTOM con colores, fuente y logo propios en el panel. No se copia la aplicación.
